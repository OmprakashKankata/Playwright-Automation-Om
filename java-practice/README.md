Java practice

Quick steps to compile and run the example on your machine (requires JDK installed and `javac`/`java` on PATH):

Windows (PowerShell or CMD):

```powershell
cd java-practice
javac HelloWorld.java
java HelloWorld
```

Unix / macOS:

```bash
cd java-practice
javac HelloWorld.java
java HelloWorld
```

If you prefer a build tool, I can add a Maven or Gradle wrapper and sample `pom.xml`/`build.gradle`.
